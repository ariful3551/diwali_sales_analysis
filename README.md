# Diwali Sales Analysis

Exploratory data analysis of Diwali sales data using Python (pandas, matplotlib).

> 🚧 Work in progress. Updated step by step.

## Dataset
Source: [Diwali Sales Dataset on Kaggle](https://www.kaggle.com/datasets/bharathid8/diwali-sales-dataset) (by bharathid8). 11,251 rows, 15 columns.

## Note
The CSV is not UTF-8. Load it with `encoding="latin-1"`.
